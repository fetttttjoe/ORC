# packages/kernel

## Facts
- packages/kernel/src/storage wraps one Postgres pool per project (PostgresStore) exposing an append-only events table (EventLog) and a derived operations index (OperationJournal), both writes serialized by a per-project advisory lock; migrate.ts checks schema version against drizzle/ SQL, system-db.ts resets/drops project databases, and redact.ts strips NULs/secrets from every event payload before it is stored. {d1c7okjc @packages/kernel #architecture-current}
- packages/kernel/src/execution wraps DBOS SDK workflows behind the ExecutionPort seam (dbos-port.ts), scheduling a plan's steps wave-by-wave (interpreter.ts) and journaling checkpoints/operations through storage. signal-router.ts reacts to log events to drive child runs/cancels/splits; exec-tool.ts and strategies/ (grounded-plan, grounding-freshness, grounding-scope) implement the acceptance-gate tool and the grounded-plan analyze/plan strategy. {re3t930z @packages/kernel #architecture-current}
- packages/kernel/src core (excl. storage/ and execution/): Kernel (kernel.ts) is the sole writer of task/plan/workspace events via EventLog transactions; projections.ts folds the append-only log into in-memory State; plugins/ wires providers/executors/skills/extensions with local trust fingerprints; config.ts resolves OrcConfig from tracked settings + env + gitignored identity. {yzr9383y @packages/kernel #architecture-current}
